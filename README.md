## 📥 نصب نرم‌افزار

1. فایل `ParsehAccounting_Setup.exe` را اجرا کنید
2. مسیر نصب را انتخاب کنید (اختیاری)
3. مراحل نصب را تا انتها ادامه دهید
4. پس از نصب، فایل `license.key` را دریافت کنید
5. فایل `license.key` را در کنار `ParsehAccounting.exe` قرار دهید
6. برنامه را اجرا کنید

---

## 🔑 دریافت لایسنس

برای دریافت لایسنس:
1. برنامه را اجرا کنید
2. HWID نمایش داده شده را یادداشت کنید
3. HWID را برای فروشنده ارسال کنید
4. فایل `license.key` را دریافت کنید
5. در کنار برنامه قرار دهید و اجرا کنید

## 🖥️ ساختار پوشه نصب

```

C:\Program Files\ParsehAccounting
├── ParsehAccounting.exe    ← فایل اصلی برنامه
├── license.key             ← فایل لایسنس (دریافتی)
├── README.md               ← این فایل
├── backups\                ← پشتیبان‌های دیتابیس
├── logs\                   ← فایل‌های لاگ
└── plugins\                ← پلاگین‌های نصب شده

```

## ❓ سوالات متداول

### برنامه اجرا نمی‌شود؟
- مطمئن شوید فایل `license.key` در کنار برنامه قرار دارد
- برنامه را به عنوان Administrator اجرا کنید

### خطای `database is locked` می‌گیرم؟
- برنامه را ببندید و دوباره اجرا کنید
- فایل `*.db-wal` و `*.db-shm` را در پوشه نصب حذف کنید

### چگونه پشتیبان بگیرم؟
- از منوی `فایل → پشتیبان‌گیری` استفاده کنید

### خروجی Excel کار نمی‌کند؟
- مطمئن شوید فایل Excel روی سیستم شما نصب است
