## 🎯 درباره نرم‌افزار

**ImanAccount** یک پلتفرم حسابداری جامع و هوشمند است که توسط شرکت **ImanAI** توسعه یافته. این نرم‌افزار با بهره‌گیری از **هوش مصنوعی اختصاصی ImanAI** و معماری **پلتفرم-محور**، راه‌حلی کامل برای کسب‌وکارهای ایرانی ارائه می‌دهد.

## 📥 نصب نرم‌افزار

### مرحله ۱: دانلود و اجرا
1. فایل `ImanAccount_setup.exe` را از وب‌سایت رسمی دانلود کنید
2. فایل را اجرا کنید
3. مسیر نصب را انتخاب کنید (پیش‌فرض: `C:\Program Files\ImanAccount`)
4. منتظر بمانید تا نصب کامل شود

### مرحله ۲: دریافت لایسنس
1. برنامه را اجرا کنید
2. **HWID** سیستم شما نمایش داده می‌شود
3. HWID را کپی کرده و برای فروشنده ارسال کنید
4. فایل `license.key` را دریافت کنید
5. فایل را در کنار `ImanAccount.exe` قرار دهید

### مرحله ۳: شروع کار
1. برنامه را اجرا کنید
2. با کاربر `admin` وارد شوید (رمز پیش‌فرض)
3. **Wizard راه‌اندازی اولیه** باز می‌شود
4. اطلاعات شرکت را وارد کنید
5. رمز عبور جدید تعیین کنید
6. شروع کنید! 🎉

## 🔑 دریافت لایسنس

### روش ۱: از طریق فروشنده
```

۱. برنامه را اجرا کنید
۲. HWID نمایش داده شده را کپی کنید
۳. برای فروشنده ارسال کنید:
├─ 📧 ایمیل
├─ 📱 واتساپ
├─ 💬 تلگرام
└─ ☎️ تلفن
۴. فایل license.key را دریافت کنید
۵. کنار برنامه قرار دهید
۶. اجرا کنید

```

### روش ۲: نسخه آزمایشی (Trial)
```

۱. در پنجره فعال‌سازی، گزینه «نسخه آزمایشی» را بزنید
۲. ۳۰ روز رایگان استفاده کنید
۳. پس از ۳۰ روز، لایسنس رسمی دریافت کنید

```

## 🔐 امنیت و اطلاعات

### محل ذخیره اطلاعات
```

📁 دیتابیس: %APPDATA%\ImanAccount\accounting.db
📁 لاگ‌ها: %APPDATA%\ImanAccount\logs
📁 پشتیبان: %APPDATA%\ImanAccount\backups\

```

### 🔒 نکات امنیتی
- ✅ تمام اطلاعات روی سیستم شماست (آفلاین)
- ✅ لایسنس با **RSA 4096** امضا شده
- ✅ رمزهای عبور با **bcrypt** هش می‌شوند
- ✅ پلاگین‌ها با **AES-GCM** رمزنگاری می‌شوند
- ✅ **بدون ارسال اطلاعات به سرورهای خارجی**

## ❓ سوالات متداول

### 🔴 برنامه اجرا نمی‌شود؟
```

✅ چک کنید فایل license.key در کنار برنامه باشد
✅ برنامه را به عنوان Administrator اجرا کنید
✅ آنتی‌ویروس را موقتاً غیرفعال کنید
✅ Microsoft Visual C++ Redistributable نصب باشد

```

### 🔴 خطای `database is locked` می‌گیرم؟
```

✅ برنامه را ببندید
✅ فایل‌های *.db-wal و *.db-shm را حذف کنید
✅ برنامه را دوباره اجرا کنید
✅ اگر ادامه داشت، با پشتیبانی تماس بگیرید

```

### 🔴 چگونه پشتیبان بگیرم؟
```

✅ از منوی فایل → پشتیبان‌گیری
✅ یا Ctrl+B
✅ پشتیبان در پوشه backups\ ذخیره می‌شود
✅ می‌توانید به فلش یا فضای ابری کپی کنید

```

### 🔴 خروجی Excel کار نمی‌کند؟
```

✅ مطمئن شوید Microsoft Excel نصب است
✅ یا فایل CSV را با Excel باز کنید
✅ نکته: از UTF-8 استفاده کنید

```

### 🔴 HWID من چیست؟
```

✅ از منوی راهنما → 🖥️ HWID
✅ یا Ctrl+H
✅ کد IACC-XXXXXXXXXXXXXXXX را کپی کنید

```

### 🔴 چطور رمز عبور را تغییر دهم؟
```

✅ از منوی فایل → 🔑 تغییر رمز
✅ یا Ctrl+P
✅ رمز فعلی + رمز جدید را وارد کنید

```

### 🔴 فراموشی رمز عبور
```

✅ در صفحه ورود، روی «فراموشی رمز» کلیک کنید
✅ کد بازیابی را وارد کنید
✅ یا با پشتیبانی تماس بگیرید

```

### 🔴 دیتابیس کجاست؟
```

✅ %APPDATA%\ImanAccount\accounting.db
✅ برای دسترسی سریع: Win+R → %APPDATA%\ImanAccount

```

### 🔴 پلاگین‌ها کجاست؟
```

✅ %APPDATA%\ImanAccount\plugins
✅ برای نصب: از بخش «مدیریت پلاگین‌ها» استفاده کنید

```
